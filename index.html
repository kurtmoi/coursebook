Install & backup

Install on this device

Checking…

  1. Open School Task Monitor in Safari.
  2. Tap the Share button (the square with an arrow pointing up).
  3. Scroll down and tap Add to Home Screen, then tap Add.
  1. Android (Chrome): tap ⋮, then Install app or Add to Home screen.
  2. Computer (Chrome or Edge): click the install icon at the right end of the address bar, or open the menu and choose Install School Task Monitor.
  3. Safari on Mac: choose File → Add to Dock.

Saved on this device

Everything you add is saved on this device and works without internet. Nothing is uploaded.

Clearing this browser's site data, or removing the app, erases what's saved. Download a backup now and then, and use it to move School Task Monitor to another device.
